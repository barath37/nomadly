# ✈️ Nomadly

A fully responsive, multi-page travel destination website built from scratch as part of the **Novians July Challenge (Task 1)**. 

The goal of this project was to strengthen core front-end fundamentals by manually coding a structured and styled website without relying on AI generation, cloning tools, or UI frameworks.

## 📄 Pages Included
- **Home (`index.html`):** Engaging hero section, floating search bar, and a grid of popular destinations.
- **About (`about.html`):** Mission statement and a features grid detailing why travelers choose Nomadly.
- **Explore (`explore.html`):** An expanded destination gallery featuring a category filter interface.
- **Contact (`contact.html`):** Split-layout design featuring contact information and a functional-looking form.
- **Login (`login.html`):** Secure access page with a split visual and form layout.

## 🛠️ Tech Stack & Concepts Applied
- **HTML5:** Semantic structuring and custom metadata implementation.
- **CSS3:** - Custom variables for consistent branding (Parchment & Terra Cotta palette).
  - **Flexbox** for navigation and alignment.
  - **CSS Grid** for responsive destination cards and footer layouts.
  - **Media Queries** for a seamless mobile and tablet experience.
